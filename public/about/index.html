From printed page to practice.

Bring your score

Use a photo, an image or a PDF. Select PDF pages, adjust the image and recognize the notation locally. MusicXML and MIDI can open directly.

Listen and review

Follow the score and piano, slow down, loop a phrase or mute a voice. Compare with the original and correct notes, timing and ties.

Play and keep it

Use touch, computer keys or a compatible MIDI keyboard. Export MusicXML, MIDI, WAV or a project backup. Your library lives in this browser.

YOUR DEVICE / YOUR MUSIC

Open a tab.
Start playing.

The online app runs entirely in your browser. GitHub Pages serves the files; recognition and audio happen on your device. Visitors do not need Node.js.

Chrome or Edge on a desktop is a good starting point. Allow audio with Enable audio. Web MIDI and audio output selection depend on the browser and connected hardware.

Launch the app

Keep it available offline

  1. Open the app and choose Settings → Prepare offline use.
  2. Keep it open until the app, piano samples and recognition models finish downloading. Models are about 158 MB.
  3. Select any additional instrument you need, then verify the app with your network disconnected.

On iPhone, use Safari → Share → Add to Home Screen, then prepare offline use from that installed app. Physical iPhone XS testing is still pending. Browser storage can be cleared; export backups regularly.

MAKE IT YOURS

Run it on your computer.

Install Node.js 22.23 or newer. Download the source ZIP, extract it and open a terminal in the extracted folder. Run these commands in order.

npm ci
npm run setup
npm run dev

Open http://localhost:5173 in your browser. Keep the terminal open while using the app. Stop it with Ctrl+C.

One setup, local processing

Setup downloads and verifies pinned libraries and recognition models. Internet is needed for this first setup. No Rust, Python or paid service is required for ordinary app use.

To create a static production build, run npm run build. Preview it with npm run preview. Opening index.html directly from the file manager will not work.

How accurate is recognition?

Recognition is experimental and can omit or misread notes, rhythm, ties, text or parts. Review the result against the original before relying on it. A clean study matched 19/19 events in a desktop smoke test; this is not a general accuracy estimate. See the known limitations.

What is downloaded or uploaded?

The site supplies app files and recognition models. Piano samples are included; other instruments download on selection from a pinned GitHub sound bank. Scores are processed locally and are not uploaded. Piano plus the last selected additional bank are retained for offline use.

Can I modify or host it?

Yes, under AGPL-3.0-only. Keep corresponding source available and preserve all third-party notices. Recognition model training-data provenance caveats are documented. Download this build’s source or read the attributions.
